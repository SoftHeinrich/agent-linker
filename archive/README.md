# Archive Layout

This repository keeps a curated active subset in `src/`:

- `ILinker1`
- `ILinker2`
- `ILinker3`
- `SLinker` through `SLinker11a`

Archived material is grouped here:

- `archive/linkers/experimental/`: removed experimental linker generations
- `archive/test_scripts/2026-03-26-v40c-retention/`: root-level tests moved during the March 2026 retention cleanup
- `archive/old_scripts/2026-03-26-v40c-retention/`: variant-specific helper scripts moved during the same cleanup
- `archive/core/`: temporarily held support modules during consolidation

The archive is intentionally not importable from the active runner.
