## Critical Anti-Patterns (do NOT repeat these)

- **Rehydrating axiom/bank slots from prompts_v2**: see anti-pattern table above. Resuming agent must refuse this even if it would help.
- **Adding numeric delta gates** (`if delta < X: skip`) to the training loop: wedges learning on regression passes; let assessor + best-bank handle decay.
- **Aggressive axiom gates that reject identity statements**: causes TM-style FN cascades. Identity / role / partial-name mentions all count as COMPONENT — only bare vocabulary, code paths, and unrelated entities are OTHER.
- **Porting s10 partial enrichment as standalone phases**: against the "skeleton + axiom slots" architecture. Generalize into coref instead.
