## Range D — Per-Backend Verdict

The user-directive gate was: gpt-5.4 STRONG_PASS triggers Claude probe; Claude must be ≥ s_linker13_min Claude BBB baseline (0.8496).

- **gpt-5.4: STRONG_PASS** (+3.29pp). Triggered Claude probe.
- **Claude: FAIL** (-4.23pp). Below the 0.8496 floor by 4.2pp.

The +3.29pp gpt-5.4 lift is genuine but cannot be claimed as a cross-backend result. Probe D's mechanism (runtime coref rubric) is **gpt-5.4-specific** on BBB — Claude's static `COREF_RULES` baseline is already near-optimal at the coref tier, and the runtime rubric's increased conservatism eats 2 TPs without offsetting gains.

### Methodological confound (declared)

The Probe D variant caches the coref rubric per `(text_stem, comp_hash)` — NOT per backend. The cached BBB rubric was built by gpt-5.4 first and **reused** by Claude. The Claude FAIL therefore reflects "Claude inference using a gpt-5.4-authored coref rubric." A Claude-built rubric would likely be MORE conservative; the gap would likely widen. The FAIL verdict stands.

## Probe A' — v4 Deadlock Resolved

**The Probe A 100% R5-reject deadlock was a vocabulary mismatch in R3, not an architectural failure in v4.**

R3 in Probe A was instructed to use textbook SE role nouns (controller, scheduler, broker, queue, dispatcher, parser, lexer, monitor, pipeline). R5 tests against 5 architectural styles where ANY role noun is style-dependent. R3 outputs were 100% R5-rejected.

Probe A' tightens R3 to **linguistic / discourse vocabulary only** (subject, predicate, antecedent, anaphora, parenthetical, qualifier clause, sentence-position, etc.) with EXPLICIT acceptable / unacceptable example wordings. R5 unchanged.

Result:
- R5 reject rate: 0% (2/2 patterns accepted)
- Linker pattern (subject-position / antecedent continuity rule) ACCEPTED with `style_dependency: null`
- Validator pattern (single-word reference + anaphora caution) ACCEPTED with `style_dependency: null`
- Linker vs validator skill banks contain **distinct** content (linker_vs_validator_different: true)
- Iter 1 F1 lifts from 0.9508 → 0.9677 (+1.69pp) by recovering 1 FN

Sample accepted pattern (linker):

> "A linker should carry forward the antecedent from an introducing sentence to a follow-up sentence when the follow-up sentence has no explicit subject but preserves discourse continuity through coordinated clause or subordinate clause structure."

This is exactly the kind of discourse-level pattern Claude naturally produces in s_linker13_clean's own internal prompts — the v4 architecture CAN converge if R3 and R5 share a compatible vocabulary spec.
