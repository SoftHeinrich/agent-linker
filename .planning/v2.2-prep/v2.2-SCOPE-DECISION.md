## Fix In Flight (Why Probe A' is not deadend)

**The R3/R5 deadlock in Probe A is a PROMPT BUG, not an architectural failure.**

R3 was told to use textbook SE vocabulary (controller, scheduler, broker, queue, etc.). R5 tested universal architectural-style transferability — which exactly those terms FAIL.

**The fix tested by Probe A' (in flight):**

- R3 vocabulary tightened to discourse / syntactic terms only: subject-position, predicate, anaphora, parenthetical, namespace prefix, section heading, sentence-position, qualifier clause, cross-reference.
- R3 vocabulary FORBIDDEN: role nouns and any architectural-style names.
- R5's 5-style transferability test unchanged.

**Why this should work** (empirical evidence): Voyager v3 Claude is naturally producing patterns exactly in this discourse vocabulary ("subject-position naming overrides predicate keywords", "section framing overrides keyword matching"). Claude self-abstracts; gpt-5.4 doesn't. Probe A' tests whether gpt-5.4 can be EXTRINSICALLY constrained to do what Claude does intrinsically.

**Fallback if Probe A' also fails**: drop to **Compact-B** (R345 single role with structured CoT, per redundancy analysis). Single LLM call internally reconciling proposal + abstraction validation. Cheapest viable architecture.
