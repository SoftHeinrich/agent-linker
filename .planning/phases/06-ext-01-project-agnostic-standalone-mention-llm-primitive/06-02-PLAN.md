Step 5 — Add the dotted-path pre-filter helper as a `@staticmethod` immediately AFTER `_parse_snum` (which is at `s_linker13.py:1107-1117`). Insert this exact body (byte-extracted from `s_linker13.py:1119-1147` — sub-variant (a) reuses ONLY the dotted/hyphen guards, not the whole regex):

```python
    @staticmethod
    def _in_dotted_or_hyphen_context_only(comp_name, text):
        """Return True iff EVERY occurrence of comp_name in text sits inside a
        dotted/hyphenated context (i.e., the regex baseline _has_standalone_mention
        would reject all matches).

        Pre-filter for EXT-01 sub-variant (a): if True, skip this sentence — do not
        pay LLM cost for a guaranteed-no candidate. EXT-02 (Phase 7) deletes this
        helper to test whether the LLM primitive can carry the dotted-path concept
        on its own. Body extracted byte-for-byte from s_linker13._has_standalone_mention
        guard lines (s_linker13.py:1138-1145).
        """
        if not comp_name:
            return False
        is_single = ' ' not in comp_name
        if is_single:
            if comp_name[0].islower():
                pattern = rf'\b{re.escape(comp_name)}\b'
            else:
                cap_name = comp_name[0].upper() + comp_name[1:]
                pattern = rf'\b{re.escape(cap_name)}\b'
            flags = 0
        else:
            pattern = rf'\b{re.escape(comp_name)}\b'
            flags = re.IGNORECASE

        any_match = False
        for m in re.finditer(pattern, text, flags):
            any_match = True
            s, e = m.start(), m.end()
            if s > 0 and text[s-1] == '.':
                continue
            if e < len(text) and text[e] == '.' and e + 1 < len(text) and text[e+1].isalpha():
                continue
            if s > 0 and text[s-1] == '-':
                continue
            if e < len(text) and text[e] == '-' and '-' not in comp_name:
                continue
            return False  # found at least one clean occurrence
        return any_match  # True iff matches existed but all were dotted/hyphen
```

Step 6 — Add the new Tier-1 batched LLM primitive `_compute_standalone_mention_map` and the lookup helper `_has_standalone_mention_llm` as instance methods of `SLinker13gPre`. Insert them immediately AFTER the `_in_dotted_or_hyphen_context_only` static method:

```python
    def _has_standalone_mention_llm(self, comp_name, snum):
        """O(1) lookup against the precomputed Tier-1 standalone-mention map.
        Returns False for unseen keys (i.e., sentences the pre-filter excluded
        or sentences whose text didn't contain comp_name)."""
        return self._standalone_map.get((comp_name, snum), False)

    def _compute_standalone_mention_map(self, sentences, components):
        """Tier-1 document-level pass: produces dict[(comp_name, snum) -> bool].

        EXT-01 sub-variant (a): regex pre-filter (_in_dotted_or_hyphen_context_only)
        strips dotted/hyphen-only contexts before the LLM judges; LLM only sees
        word-boundary-clean candidates. Per-component batched scan (50 sents/batch)
        following the _run_single_extraction_pass shape at s_linker13.py:748-803.

        Approve-biased fallback on LLM failure: mark every batch sentence as standalone=True
        (matches the verified.extend(valid_seeds) pattern at s_linker13.py:567-568).
        """
        comp_names = self._get_comp_names(components)
        smap = {}

        for cname in comp_names:
            # Cheap textual pre-narrowing + dotted/hyphen pre-filter (sub-variant a)
            cand_sents = [
                s for s in sentences
                if cname.lower() in s.text.lower()
                and not self._in_dotted_or_hyphen_context_only(cname, s.text)
            ]
            if not cand_sents:
                continue

            for batch_start in range(0, len(cand_sents), 50):
                batch = cand_sents[batch_start:batch_start + 50]
                prompt = f"""{STANDALONE_MENTION_RULES_PRE_FILTERED}

COMPONENT: {cname}
SENTENCES:
{chr(10).join(f"S{s.number}: {s.text}" for s in batch)}

Return JSON: {{"results": [{{"component": "{cname}", "sentence": N_INTEGER, "standalone": true}}]}}
JSON only:"""

                data = None
                for attempt in range(2):
                    data = self.llm.extract_json(self.llm.query(prompt, timeout=120))
                    if data and data.get("results"):
                        break
                    if attempt == 0:
                        print(f"    Standalone-mention [{cname}] empty response, retrying...")

                if not data:
                    # Approve-biased fallback — protect recall on LLM failure
                    for s in batch:
                        smap[(cname, s.number)] = True
                    continue

                for r in data.get("results", []):
                    snum = self._parse_snum(r.get("sentence"))
                    if snum is not None:
                        smap[(cname, snum)] = bool(r.get("standalone", True))

        return smap
```
