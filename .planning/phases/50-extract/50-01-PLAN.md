<objective>
Build a single standalone extraction script that converts every frozen
`s_linker20_union` per-run phase_cache (the v2.6.5 ship candidate, both backends,
runs 1-3, all 5 projects = 30 cells) into one neutral, stdlib-loadable JSON per
cell, and machine-verifies each extract against that cell's own `*_links.csv`.

Purpose: the downstream eval bundle (Phases 52-55, vendored under `../working/`)
must replay RQ3/RQ4 without ever importing the linker classes or touching pickle.
The JSON produced here is the contract for every later phase.

Output: `scripts/extract_s20union_caches.py` (extractor + built-in faithfulness +
coverage gate) and 30 deterministic neutral JSON extracts under
`results/v2.6.6_extracts/<backend>/<run>/<project>.json`.

This phase is pure, mechanical, READ-ONLY over the caches: no LLM, no network,
deterministic. The only "logic" is faithful structure-preserving serialization;
every bug risk is a serialization bug, which the per-cell faithfulness assertion
catches.
</objective>
