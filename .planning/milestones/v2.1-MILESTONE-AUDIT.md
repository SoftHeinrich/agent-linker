## Methodological Contributions

1. **Scenario-E framing**: gate relaxation as a function of prompt-reduction depth. Static-distillation variants on tighter gates; runtime-mechanism variants on relaxed gates. Frontier map instead of strict pass/fail.
2. **GATE-06 cross-dataset isolation operationalization** (Phase 12 Plan 12-05 revisit): the empirically testable criterion for runtime LLM discovery is "term in dataset A's runtime output is a leak iff (a) it is a component of dataset B≠A AND (b) NOT in A's PCM AND (c) NOT in A's input doc". This replaces strict-grep on outputs with a meaningful methodological standard.
3. **Single-step ablation harness** (Phase 12 Plan 12-02): checkpoint-loaded single-phase re-runs reduce per-trim cost by ~5-10×. Cross-stage dependency contract documented.
4. **Voyager-TLR train-test methodology**: validated as operational (no overfit collapse, GATE-06 abstraction survives iteration) on gpt-5.4. Result: no measured F1 headroom above hand-distilled v2.1 baselines on this benchmark — methodology shipped for v2.2 anchor.

## Findings (Publishable)

1. **Lossless rule distillation + reasoning-before-conclusion ordering** (trim1): improves macro F1 on BOTH Claude (+0.5pp vs baseline) AND gpt-5.4 (+0.96pp). Largest cross-model improvement: TM gpt-5.4 +10.08pp.
2. **Runtime rubric generation works for narrow Tier 2 judges** (trim9 seed disambiguation): ships across both backends. Generalizes from 12-05's alias-judge baseline.
3. **Textually-lossless prompt merges can be semantically lossy** (12-04 deep investigation): role-divergent routing in proposer/judge boundaries is load-bearing.
4. **Cross-model penalty is consistent ~3-4pp** for runtime-mechanism variants regardless of target prompt: model-capability finding, not mechanism failure.
5. **6/6 runtime variants ACCEPT under Scenario E** but only 1/6 ACCEPT under original strict gate: the prompt-reduction × accuracy frontier is mappable.
