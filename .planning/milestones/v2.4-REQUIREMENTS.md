## Locked Decisions

These design decisions were finalized in the v2.3 post-mortem conversation and must not be re-explored.

| Decision | Lock | Rationale |
|----------|------|-----------|
| Gate A: FM citation required, non-advisory | Reject on empty list | Advisory mode was tried implicitly in v2.3 — split2 produced 0 commits. Non-advisory is the fix. |
| Gate B: LLM dual-direction judge | `fixes_cited_fm: true AND causes_new_error: false AND confidence: high\|medium` | Replaces stochastic F1-delta comparison. ~$0.01/pass. |
| Drop probation re-run | Gate A/B replace it entirely | Two independent L runs were the root cause of noise (±3.4–3.8pp variance swamped signal). |
| Gap 1 fix: COREF_RULES extension | Not DOC_KNOWLEDGE_EXTRACTION_RULES | Entity extraction (line 785-803) is batch-mode (50 sents) with no window context; local aliases filtered at lines 788-791. Coref has ±5 window (lines 969-973) — the correct location. |
| Gap 1 fix: code change required | ~8 lines in `_coref_cases_in_context` | COREF_RULES axiom change has zero effect without widening the sentence filter; SCN sentences contain no pronoun and never reach LLM. |
| Gap 2 fix: axiom only | No code change | 0/27 MS gold + 0/23 TS gold sentences start with gerund — empirically safe. |
| Gap 3 fix: one phrase in COREF_RULES | "or aliased" added | ANTECEDENT_ALIAS_GUIDE path already exists in code (line 1017 checks `antecedent_via_alias`). Only the axiom instruction was missing. |
| Gaps 1 + 3 combined | Single COREF_RULES update | Both are anaphoric resolution failures; one unified semantic reframing is cleaner. |
| Canonical baseline | `s_linker13_min` unchanged | gpt-5.4 macro 0.9069; Claude macro 0.9506. Frozen throughout v2.4. |
