## Accomplishments

3. **`ABLATION-TABLE.md`** rendered via `tabulate(..., tablefmt="github")`: 12-column table with the 4 LOCKED footnotes (13d failure, s_linker13 provenance, 12c BBB-rerun provenance, D-47 paper macros).
4. **`ABLATION-TABLE.tex`** rendered via `tabulate(..., tablefmt="latex_booktabs")` with a % comment block prepended listing all 8 raw variant identifiers. tabulate handles `_/&/%` escaping automatically.

## JSON-vs-D-47 Sanity Check (Task 1c, Task 1d discrepancy report)

Per D-47a, JSON wins; the markdown's "**D-47 paper macros (rounded reference)**" footer quotes 0.9405/0.9509/etc so the canonical paper numbers remain visible alongside the JSON-derived render values. Grep checks for `0.9405` and `0.9509` pass via this footer.

- (b) 13d row: macro left NaN per D-46c (hard-tier only, no full-sweep). The TM F1 value (0.750) IS shown in the TM column for context; MS/TS/BBB/JAB blank.
