## Active v2.5 Requirements

### INFRA — Infrastructure Bug Fixes

- [ ] **REQ-V25-01** — Oracle cache key includes `bank_content_hash`. In `voyager_train_tlr_v4_beta.py` line 455, oracle key changes from `{text_stem}_{comp_hash}_{backend}_{model}_oracle_iter{iter_num}` to include `bch = _bank_content_hash(bank)` in the key (same pattern as L cache). This prevents split-3 TM from reusing mainline oracle outputs when the bank state differs. One-line fix; same pattern as the L cache fix already in place.

- [ ] **REQ-V25-02** — Probation min-commit threshold raised to `delta >= 0.005` (was `delta > 0`). This filters ±3–4pp BBB LLM run-to-run variance from the probation decision. No additional LLM calls required. Applies to all splits.

- [ ] **REQ-V25-03** — D prompt includes an explicit underfilled-slot list after bank-state display. After showing per-slot pattern counts, the prompt text identifies zero-pattern slots as high-priority proposals targets (e.g., ENTITY_EXTRACTION_RULES, AMBIGUITY_FEW_SHOT, DOC_KNOWLEDGE_JUDGE_EXAMPLES, and any new slots starting empty). This steers D away from over-proposing DOC_KNOWLEDGE_EXTRACTION_RULES when other slots are empty.
