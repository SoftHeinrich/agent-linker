## v2.4 Goal

Fix the three v2.3 debts (broken probation gate D-1 + axiom vocabulary ceiling D-2/D-3) and re-run β training with improved infrastructure to close the 0.19pp gap to canonical (`s_linker13_min` at 90.7%) and aim for STRONG (≥ 0.9173).

**Canonical baseline going in**: `s_linker13_min` (Claude macro 0.9506, gpt-5.4 macro 0.9069). Unchanged throughout v2.4.

**Outcome verdict options:**
- **STRONG (≥ 0.9173):** `s_linker14_voyager` promoted; traceability gate validated as production-grade.
- **WEAK ([0.87, 0.9173)):** Ships with documented caveat; fixed gate + improved axioms documented as research finding.
- **FAIL (< 0.87):** Training infrastructure failure despite gate fix — publish negative finding with root-cause.

`s_linker13_min` retains `canonical=True` throughout regardless of outcome.

## Phase Details

### Phase 20: Infrastructure Prep

**Goal**: All three v2.3 debts are addressed in code and prompts — traceability gate replacing broken F1-delta gate, axiom improvements covering the 3 vocabulary gaps — and a 5-dataset eval of the axiom-improved `s_linker14_voyager` is recorded as the pre-training baseline before any Phase 21 budget is spent.
**Depends on**: Nothing (first phase of v2.4; v2.3 shipped).
**Requirements**: REQ-V24-01, REQ-V24-02, REQ-V24-03, REQ-V24-06, REQ-V24-07, GATE-01, GATE-06, GATE-07
**Success Criteria** (what must be TRUE):
  1. Gate A implemented: D prompt includes `addresses_failure_modes` field; harness rejects proposals with empty list or non-existent FM IDs; probation re-run loop removed.
  2. Gate B implemented: LLM dual-direction judge prompt and response parsing in place; accept condition (`fixes_cited_fm: true AND causes_new_error: false AND confidence: high|medium`) enforced.
  3. 4 supporting bugs fixed: L cache keyed on (project, bank_content_hash, backend, model); `prior_f1s` uses committed state; per-project candidate bank in probation; `committed_macro >= CONVERGENCE_THRESHOLD` as convergence condition.
  4. COREF_RULES axiom updated: anaphoric framing covers SCN (role-referential NPs) + alias antecedent support. `_coref_cases_in_context` expanded with `role_ref_pat` terminal-word filter (~8 lines).
  5. SEED_DISAMBIGUATION_RULES axiom updated: gerund/capability-description rejection rule added.
  6. 5-dataset eval (gpt-5.4) of axiom-improved `s_linker14_voyager` with cross_split_final_bank completed and recorded as Phase 20 baseline; DEFAULT_BANK_PATH updated to cross_split_final_bank.json.
  7. GATE-06 check passes on all axiom text changes (no benchmark vocabulary introduced).
**Plans**:
- [ ] 20-P1-PLAN.md — Traceability Gate implementation in `scripts/voyager_train_tlr_v4_beta.py` (Gate A + Gate B + 4 bug fixes + drop probation re-run)
- [ ] 20-P2-PLAN.md — Axiom improvements in `src/llm_sad_sam/linkers/experimental/prompts_v3_axiom.py` (COREF_RULES: SCN anaphoric + alias coref; SEED_DISAMBIGUATION_RULES: gerund rejection) + code change in `src/llm_sad_sam/linkers/experimental/s_linker14_voyager.py` `_coref_cases_in_context`
- [ ] 20-P3-PLAN.md — 5-dataset eval of axiom-improved `s_linker14_voyager` (gpt-5.4); update DEFAULT_BANK_PATH; record as Phase 20 pre-training baseline
