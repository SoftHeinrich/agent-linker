## v2.3 Goal

Implement the β multi-role training harness (L + O + D-with-CoT-A + P), train it against gpt-5.4 on the mainline split (MS+TS+TM train, BBB+JAB test), and determine whether multi-role training produces per-slot pattern banks that match or beat hand-authored `prompts_v3.py` on gpt-5.4 macro F1.

**Outcome verdict options:**
- **STRONG (≥ 0.9173):** `s_linker14_voyager` ships as `experimental=True` with no caveat.
- **WEAK ([0.87, 0.9173)):** Ships with documented caveat; research value confirmed.
- **FAIL (< 0.87):** v4 dropped; Compact-B fallback activates (Phase 18).

`s_linker13_min` retains `canonical=True` throughout regardless of outcome.

**Goal**: All code components of the β architecture are implemented, tested, and ready to accept a real gpt-5.4 training run — no LLM budget consumed during this phase.

**Requirements**: REQ-V23-01, REQ-V23-02, REQ-V23-03, REQ-V23-04, REQ-V23-09, REQ-V23-10, REQ-V23-11, REQ-V23-12, GATE-02, GATE-06, GATE-07
**Success Criteria** (what must be TRUE):
  1. `scripts/voyager_train_tlr_v4_beta.py` runs dry-run mode (no LLM calls) end-to-end on a single project with no errors, exercising L → O → D → P iteration loop.
  2. `src/llm_sad_sam/linkers/experimental/s_linker14_voyager.py` runs on all 5 datasets (axiom-only / empty bank mode) and produces valid link output.
  3. `s_linker14_voyager` is registered in `CANONICAL_VARIANTS` + `VARIANT_SPECS` with `experimental=True` and a structured docstring per GATE-07.

  5. Per-(text_stem, comp_hash, backend, model) cache reads/writes correctly for a synthetic LLM output, with `VOYAGER4B_CACHE_ROOT` env override working.
  6. GATE-02 frozen-compat regression test still passes (all CANONICAL_VARIANTS unaffected).

### Phase 15: Probe Tier

**Goal**: The β training harness runs 1–2 outer passes on the mainline split (gpt-5.4) within the $5–10 budget, and a binary go/no-go verdict is available to decide whether to continue to Range or kill v4.
**Depends on**: Phase 14
**Requirements**: REQ-V23-07, REQ-V23-13, REQ-V23-14 (Probe tier)
**Success Criteria** (what must be TRUE):
  1. Outer pass 1 completes on all 3 training projects (MS + TS + TM) and per-project F1 is logged.
  2. Training-project macro F1 after pass 1 is recorded and compared to the 0.87 cheap-kill floor.
  3. If pass-1 macro F1 ≥ 0.80 (not yet killed), outer pass 2 runs.
  4. Probe-tier verdict (CONTINUE / KILL) is documented with numeric evidence. If KILL, Phase 18 Compact-B is flagged as next action.
  5. Per-iter bank state (per-project `_bank.json` at the end of each pass) is persisted and readable.
  6. Total gpt-5.4 cost for the Probe tier is logged; remains ≤ $10.

### Phase 16: Range Tier

**Goal**: β training converges (macro ≥ 0.90 on training projects, or max 5 outer passes reached), the final aggregated bank is evaluated on all 5 datasets, and the 3-tier promotion verdict is computed — providing enough evidence to decide whether to run the 3-split Confirmation sweep.
**Depends on**: Phase 15 (CONTINUE path only)
**Requirements**: REQ-V23-05, REQ-V23-07, REQ-V23-13, REQ-V23-14 (Range tier), REQ-V23-15
**Success Criteria** (what must be TRUE):
  1. Training converges (macro ≥ 0.90) or stops at outer pass 5; per-pass macros are logged and the converged-early bank is preserved.
  2. Final aggregated bank (`results/voyager_v4_beta/mainline/final_bank.json`) contains patterns for all 9 axiom slots.
  3. `s_linker14_voyager` evaluated on all 5 datasets (gpt-5.4); per-dataset F1 and macro F1 recorded.
  4. Secondary comparison vs `prompts_v3_axiom.py` (axiom-only floor) is available to attribute lift to trained patterns.
  5. 3-tier verdict (STRONG / WEAK / FAIL) is documented against the locked bar (≥ 0.9173 / [0.87, 0.9173) / < 0.87).
  6. Total gpt-5.4 cost for the Range tier is logged; remains ≤ $25.

**Depends on**: Phase 15 (KILL path) OR Phase 16 (FAIL verdict) — CONDITIONAL
**Requirements**: REQ-V23-08 (fail path), REQ-V23-14 (Compact-B budget)
**Success Criteria** (what must be TRUE):
  1. `scripts/voyager_train_tlr_v4_compact_b.py` implements the R345 single-CoT-role architecture (error categorization + pattern distillation + abstraction validation in one LLM call).
