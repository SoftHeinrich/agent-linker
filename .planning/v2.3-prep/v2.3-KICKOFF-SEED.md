## Resolved Decisions (locked via /gsd:explore 2026-06-01)

The sub-questions enumerated in the earlier draft of this seed are now resolved. Recorded here so the v2.3 milestone planner treats them as decisions, not open questions.

### Architectural Endpoint — (A) Voyager-Bank Canonical

v2.3 ships **Voyager v4 trained skill bank** as the mainline mechanism. Bank fills ALL slots uniformly via R3 distillation → injected into all axiom prompts.

Ruled out:
- **(C) Hybrid (runtime in some slots, bank in others)** — slot asymmetry is ugly by construction. Cherry-picking one slot for runtime treatment while leaving others static creates an inconsistent linker. Not pursued.
- **(B) Full runtime-rubric linker** — DEMOTED to contingency only. Acceptable only IF v4 fails AND (B) is reconsidered AND ALL LLM-using slots get runtime conversion simultaneously (no single-slot exceptions). Spike candidates (alias-rubric, extraction-rubric) therefore demoted to "contingency-only, run only if v4 falsified."

Slot-asymmetry-is-ugly principle: a linker's LLM-using slots must use the SAME mechanism class. Either all-static, all-bank-injected (v4), or all-runtime-rubric (B). Mixed-mechanism linkers are rejected on aesthetic + reviewer-defensibility grounds.

Note: the Probe D opt-in carve-out shipped in v2.2 is a single-slot anomaly. Acceptable because it is gpt-5.4-only opt-in, NOT the canonical linker. The canonical (`s_linker13_min`) remains uniform-static.
