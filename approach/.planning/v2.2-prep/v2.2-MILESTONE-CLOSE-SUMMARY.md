- Mechanism: 5-role training harness (R1 actor, R2 generalizer, R3 distillator, R4 categorizer, R5 abstraction validator) generating a skill bank. R3 distillator vocabulary: textbook SE terms (controller, scheduler, broker, queue, cache).
- Failure mode: R5 5-style transferability test marked textbook SE terms as "style-dependent" → 100% R5 reject → deadlock.
- Decision: PROBE_FAIL (falsification criterion hit — 100% reject is the v2.2 falsification threshold per SCOPE-DECISION).
- Retained artifact: `scripts/voyager_train_tlr_v4.py`

**Probe A' — Voyager v4 vocab fix (discourse/syntactic R3 vocabulary)**
- Mechanism: same v4 architecture; R3 tightened to discourse/syntactic terms only (subject-position, predicate, anaphora, parenthetical, namespace prefix, section heading, qualifier clause, cross-reference). FORBIDDEN: role nouns + architectural-style names.
- Outcome: mediastore gpt-5.4 STRONG_PASS (+1.69pp); BBB gpt-5.4 WEAK_PASS (R5 0/8, F1 -0.24pp). v4 is dataset-conditional — architecture is not universally promotable across the 5-project benchmark.
- Decision: DEFERRED to v2.3 as starting point (not re-explored; vocab fix is the new baseline).
- Retained artifact: `scripts/voyager_train_tlr_v4_a_prime.py`

**Probe B — Preamble + cached rubric (INFER-01)**
- Mechanism: LLM-built per-dataset alias-judge rubric injected as system preamble. One builder call per dataset; rubric cached.
- Failure mode: cold-generated per-dataset rubric introduced an over-aggressive token-reject rule producing 4 FNs vs anchor's 1 → -5.24pp. Failure class: cold-generated per-dataset rubrics over-restrict at scale (contrasts with trim9/Probe D which replace narrow rules rather than the full judge rubric).
- Decision: DECLINED. Mechanism not viable as designed.
- Retained artifact: `s_linker14_probe_b_preamble_clean.py` (`canonical=False`)

**Probe C — Self-Refine on alias judge (INFER-02)**
- Mechanism: 2-iteration Self-Refine; iter-0 contested links re-submitted with critique context; iter-1 decision replaces iter-0.
- Outcome: +0.00004pp. 80% iter-0 contested rate but iter-1 fired without changing the approved set.
- Failure mode: judge at ceiling on mediastore — residual error near zero, Self-Refine has no signal to improve on.
- Decision: DECLINED as primary (GATE-08 cost flag: doubled judge cost, zero gain). Contingent fallback only if v2.3 mainline fails.
- Retained artifact: `s_linker14_probe_c_selfrefine_clean.py` (`canonical=False`)
