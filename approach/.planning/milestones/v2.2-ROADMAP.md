## v2.2 Goal

Validate via a parallel probe wave whether any of 4 mechanism pillars could lift macro F1 on either backend without regressing the other:

1. **Pillar A — Voyager v4 multi-role architecture (R1–R5)**: train-test methodology deferred from v2.1; gpt-5.4 pilot confirmed operational but near zero headroom over baseline. Re-probed with 5-role architecture.
2. **Pillar B — Problem-statement preamble + cached rubric (INFER-01)**: LLM-built per-dataset rubric injected as system preamble to boost judge precision without code changes.
3. **Pillar C — Self-Refine on alias judge (INFER-02)**: 2-iteration Self-Refine on the Tier-2 alias judge to recover proposer-side FNs.
4. **Pillar D — Upstream-tier rule removal (EXT-upstream)**: runtime per-dataset coref rubric replaces static `COREF_RULES`; mechanism class proven in v2.1 trim9.

**Outcome:** 4 probes ran on mediastore gpt-5.4. One strong survivor (Probe D). Range D extended to BBB: gpt-5.4 STRONG_PASS (mean +2.2pp), Claude FAIL (confounded by cross-backend cache reuse). Cache-fix landed; Claude re-test methodologically unblocked. Decision: ship `s_linker13_min` unchanged as canonical + Probe D as opt-in gpt-5.4-only carve-out + defer Voyager v4 + per-backend cache infra + Probe A' vocab fix to v2.3.
